# FTS-ANFIS-BN Cognitive Load Pipeline

Project nay xay dung pipeline phan loai cognitive load tu 4 tin hieu sinh ly:

```text
Raw physiological windows
  -> FTS encoder
  -> per-signal ANFIS models
  -> Bayesian fusion
  -> P(task)
```

Muc tieu chinh cua codebase la chay thi nghiem subject-independent: train/CV tren tap subject train, chon threshold bang OOF prediction, sau do retrain tren full train va danh gia mot lan tren held-out test subjects.

## Quick Start

Tu thu muc project `fts-anfis-bns-final/`:

```bash
pip install -r requirements.txt

# Chay mot preset/pipeline
python main.py --preset A2_soft --ablation exp1

# Chay cac nhom thi nghiem co san
python run_experiments.py --group exp1
python run_experiments.py --group exp2
python run_experiments.py --group exp3
python run_experiments.py --group all

# Mo dashboard
streamlit run app.py
```

Neu chay tu Jupyter notebook:

```python
%run main.py
```

## Main Entry Points

### `main.py`

Dung cho mot lan chay don le. File nay:

- build `ExperimentConfig` tu preset, constants trong file, va CLI args
- load dataset
- goi `run_one_experiment()`
- co the ghi CSV, in per-subject metrics, dump rules/CPT, export artifacts

Vi du:

```bash
python main.py --preset A2_soft --ablation exp1 --dump-rules --show-per-subject
python main.py --preset A2_soft --ablation exp2 --fusion weighted_mean
python main.py --preset A2_soft --ablation exp3 --fts-summary-mode entropy
python main.py --preset A2_soft --ablation exp4
```

### `run_experiments.py`

Dung cho chay nhieu variant theo group:

- `exp1`: so sanh FTS membership function type
- `exp2`: so sanh so luong ANFIS rules
- `exp3`: so sanh contribution cua cac stage
- `all`: chay ca 3 group

Vi du:

```bash
python run_experiments.py --group exp1
python run_experiments.py --group all
```

### `app.py`

Streamlit dashboard de chay pipeline va xem:

- overview config/dataset
- OOF va held-out test metrics
- threshold sweep
- per-subject metrics
- sample-level explanation cho full pipeline
- BN prior/CPT/signal weights/inference trace
- ANFIS rule bases

Chay:

```bash
streamlit run app.py
```

## Pipeline Flow

Code chay theo protocol sau:

```text
DatasetSplit
  -> run_cv_result()
       GroupKFold by user_train
       fit stages on train fold only
       predict validation fold
       collect OOF posterior
  -> find_best_threshold()
       choose threshold from OOF only
  -> retrain_and_test_result()
       retrain on full train split
       evaluate held-out test split once
  -> RunResult
       metrics, predictions, trained models, optional artifacts
```

`runner.py` la orchestration layer hien tai. `pipeline.py` giu API thap hon cho CV/retrain va van co wrapper legacy:

- `run_cv_result()` -> `CvResult`
- `run_cv()` -> legacy tuple `(oof_post, oof_y, fold_indices)`
- `retrain_and_test_result()` -> `TestResult`
- `retrain_and_test()` -> legacy tuple `(pred, post, metrics, models)`

- `config.py`: dataclass `ExperimentConfig` va `setup_seed()`
- `presets.py`: `EXPERIMENT_PRESETS` va `apply_preset()`

`config.py` van re-export preset helpers de giu compatibility, nhung code moi nen import preset tu `presets.py`.

### Data and Features

- `data.py`: doc Excel files, binarize labels, tao fixed train/test subject split
- `features.py`: feature helpers cho ablation
- `stages.py`: dispatch Stage 1 theo `cfg.ablation`

Feature paths:

- full / no-BN / no-ANFIS: dung `FTSEncoder`
- no-FTS: dung statistical features tu raw windows
- no-ANFIS: summarize FTS features thanh 1 evidence score per signal

### Training

- `training.py`: train mot `ANFIS_TSK` cho moi signal va optional calibration
- `fusion.py`: tao BN/TAN fusion model, tinh reliability weights, fuse without BN
- `pipeline.py`: chay CV va retrain/test
- `runner.py`: chay full experiment end-to-end

### Results and Reporting

- `results.py`: typed result containers `CvResult`, `TestResult`, `RunResult`, `TrainedModels`
- `metrics.py`: threshold search, metrics, per-subject metrics, console metric printing
- `csv_reporting.py`: CSV columns, result row builder, CSV append
- `console_reporting.py`: ANFIS rules, FTS transitions, BN/TAN CPT console dumps
- `reporting.py`: compatibility facade cho code cu

### Artifacts and Dashboard Export

- `artifacts/bn_serializer.py`: tao BN artifact dict khong ghi file

## Models

### `FTSEncoder`

File: `src/fbn_pipeline/models/fts_encoder.py`

Stage 1. Bien raw time window `(N, 4, T)` thanh transition features:

- membership functions: `triangular`, `gaussian`, `trapezoid`, `gbell`
- normalization: `total_sum` hoac `row`
- output shape: `(N, 4 * n_sets^2)`

### `ANFIS_TSK`

File: `src/fbn_pipeline/models/anfis_tsk.py`

Stage 2. Moi signal co mot ANFIS model rieng. Model dung TSK/Sugeno style:

- premise MF: `gaussian` hoac `gbell`
- rule centers khoi tao bang KMeans
- consequent layer fit bang ridge least squares
- premise parameters update bang gradient descent
- output la probability `P(task | signal_s)`

### `BNFusion`

File: `src/fbn_pipeline/models/bn_fusion.py`

Stage 3 naive Bayesian fusion:

```text
Task -> E_Temp
Task -> E_HR
Task -> E_GSR
Task -> E_RR
```

Ho tro:

- hard evidence qua quantile bins
- soft evidence qua Gaussian membership over bins
- reliability weighting bang per-signal AUC
- `explain_sample()` cho inference trace

### `TANFusion`

File: `src/fbn_pipeline/models/bn_dependent.py`

Tree-Augmented Naive Bayes fusion. Dung khi `cfg.bn_structure` la `"tan"` hoac `"dependent"`.

### `FusionModel`

File: `src/fbn_pipeline/models/fusion_protocol.py`

Protocol chung cho cac fusion model. Code export/reporting chi can biet model co:

- `fit()`
- `predict_proba()`
- `predict()`
- `get_cpt_table()`
- `get_signal_weights()`
- `explain_sample()`

## Ablation Variants

Canonical values trong `Ablation`:

| Value | Meaning | Pipeline |
| --- | --- | --- |
| `exp1` | full pipeline | FTS -> ANFIS -> BN |
| `exp2` | no BN | FTS -> ANFIS -> mean/weighted mean |
| `exp3` | no ANFIS | FTS summary -> BN |
| `exp4` | no FTS | statistical features -> ANFIS -> BN |

Important: trong `run_experiments.py`, experiment group `exp2` la "number of ANFIS rules", nhung cac preset `EXP2_RULES_*` van dung ablation `exp1` vi pipeline van la full FTS -> ANFIS -> BN.

## Evaluation Protocol

Project tranh leakage theo cac diem sau:

1. Held-out test subjects khong dung trong CV.
2. `GroupKFold` split theo `user_train`, nen sample cung subject khong roi vao ca train va validation trong cung fold.
3. Feature encoder, ANFIS, calibration, BN bins/CPT deu fit trong train fold.
4. Threshold duoc chon tu OOF predictions.
5. Held-out test chi duoc danh gia sau khi retrain tren full train.
